# Build Management

This document provides instructions on how to access and understand the "Build" tab.

## Accessing the Build Tab

1. From the "Home" page, select an application.

2. Navigate to the "Build" tab.

<img src="../../assets/build.jpg" width="500" alt="Build tab in application">

> **_NOTE:_** To learn more about the policies, refer to the [Code Quality tutorial](../code-quality.md).



> **Note:** The Build page allows you to view and manage build versions, providing insight into your application's development history and enabling you to track changes over time.
