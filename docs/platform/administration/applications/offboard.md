# Offboard

This document provides instructions on how to offboard an application.

## Offboarding an Application

1. From the "Home" page, select  the application you want to offboard.
2. Navigate to the "Settings" tab.

<img src="../../../../assets/images/offboarding1.jpg" width="500" alt="Application settings page">

3. Click the "Delete" button.
4. A pop-up window will appear.
5. Input the app name.
6. Click "Delete app" to delete the application.

<img src="../../../../assets/images/offboarding2.jpg" width="500" alt="Delete application confirmation pop-up">

> **Note:** Ensure you want to permanently delete the application before confirming, as this action cannot be undone.
