# Application Onboarding

This document provides instructions on how to onboard a new application.

## Creating a New Application

1. On the home page, click on the "Create app" button.

<img src="../../../../assets/images/create_new_application.jpg" width="500" alt="Create new application button">

2. In the pop-up window, fill in the fields for "App name" and "App tenant".
3. Click on the "Create app" button.

<img src="../../../../assets/images/create_new_component.jpg" width="500" alt="Create new application pop-up">

4. Wait for the application to be created. This process may take a few minutes.

<img src="../../../../assets/images/component_creating.jpg" width="500" alt="Application creation in progress">

5. Once the application is created, it will appear in the list of apps on the home page.

<img src="../../../../assets/images/component_created.jpg" width="500" alt="New application in the app list">

> **Note:** Allow a couple of minutes for the application to create.
