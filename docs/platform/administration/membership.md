# Team Memberships

This guide provides step-by-step instructions for managing a user's team membership in the Administration section.

## Adding a User to a Team

1. Navigate to the "Administration" tab in the upper left corner of the Low-Ops Portal.

<img src="../../../assets/images/administration.jpg" width="500" alt="Administration tab in Low-Ops Portal">

2. In the left menu, select the "Users" tab.
3. Click on the user you want to add to a team.
4. Scroll to the "User teams" section.
5. Click the "Join team" button.

<img src="../../../assets/images/user_teams.jpg" width="500" alt="User teams section in user profile">

6. In the pop-up window, select the checkboxes for the teams you want to add the user to.
7. Click the "Join" button.

<img src="../../../assets/images/join_team.jpg" width="500" alt="Join team pop-up window">

8. The joined teams will appear in the "User teams" section.

## Removing a User from a Team

1. In the user's profile, scroll to the "User teams" section.
2. Find the team you want to remove the user from and click the "Leave team" button next to it.

<img src="../../../assets/images/leave_team.jpg" width="500" alt="Leave team button in User teams section">

3. In the pop-up window, click the "Leave" button to confirm.

<img src="../../../assets/images/leaving_team.jpg" width="500" alt="Leaving team confirmation pop-up">

> **Note:** Removing a user from a team may affect their access to certain resources or applications.
